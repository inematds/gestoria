What it is

Manage work, from process to evidence.

The first version works with local data and fictional scenarios. It does not run models or access CRM, ERP, or email. Real integrations have a separate technical plan.

🧭 Processes and roles

Define an objective, a human owner, steps, and a target. Give each agent a mission, inputs, deliverables, and limits.

🧭 Autonomy and review

Simulate normal situations and exceptions. Record human decisions and check the promotion criteria for each version.

🧭 Evidence and improvement

Compare expected and produced results, track metrics, and document experiments in the LOOP-R cycle.

User guide

From the first process to documented improvement.

The sales qualification example is fictional. Use it to learn the workflow, then add your own scope using anonymized data.

1

Open the published version

Use the “Open tool” button. To run a local copy, execute:

git clone https://github.com/inematds/gestoria.git
cd gestoria
npm install
npm run dev
2

Map the process

In Processes, create an operation with an objective, owner, steps, volume, current time, and target. Start with a narrow scope, such as preparing sales qualification.

3

Create the digital role

In Workforce, record the mission, inputs, output, owner, and what the agent can and cannot do. Tools, model, and Skills are metadata planned for this version.

4

Simulate and review

In Overview, choose a process and simulate a routine, conflicting data, or a request outside the policy. In Human Decisions, approve it or send it back with a reason.

5

Evaluate the version

Record the expected result, the result produced, and the human classification. Check the agent profile: educational promotion requires 100 cases from the current version, the target met, no critical errors, and all pending items resolved.

6

Close the improvement loop

In Continuous Improvement, record the problem, hypothesis, and test. Add evidence to validate and promote an experiment. Changing the agent creates a new version and requires a new evaluation.

7

Save and retrieve your work

In Lab Data, export the JSON copy. Importing replaces the current records after confirmation. There is no account or syncing between devices.

The working tool.

Real app capture with the initial fictional data. Metrics are calculated from the lab records.

How to read the metrics

A human approval increases the number of completed cases, but not the autonomous work. Pending and returned cases are shown separately.

Cost includes all attempts. Evaluations count only for the agent’s current version.
