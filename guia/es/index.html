Qué es

Gestiona el trabajo, del proceso a la evidencia.

La primera versión funciona con datos locales y escenarios ficticios. No ejecuta modelos ni accede a CRM, ERP ni correo electrónico. Las integraciones reales tienen un plan técnico aparte.

🧭 Procesos y cargos

Define el objetivo, al responsable humano, las etapas y la meta. Asigna a cada agente una misión, entradas, entregas y límites.

🧭 Autonomía y revisión

Simula situaciones normales y excepciones. Registra decisiones humanas y consulta los criterios de promoción de cada versión.

🧭 Evidencia y mejora

Compara lo esperado con lo producido, sigue los indicadores y documenta experimentos en el ciclo LOOP-R.

Guía de uso

Del primer proceso a la mejora documentada.

El ejemplo de calificación comercial es ficticio. Úsalo para conocer el flujo y luego registra tu propio recorte con datos anonimizados.

1

Abrir la versión publicada

Usa el botón “Abrir herramienta”. Para ejecutar una copia local, ejecuta:

git clone https://github.com/inematds/gestoria.git
cd gestoria
npm install
npm run dev
2

Mapear el proceso

En Procesos, crea una operación con objetivo, responsable, etapas, volumen, tiempo actual y meta. Empieza por un segmento, como preparar la calificación comercial.

3

Crear el puesto digital

En Fuerza de trabajo, registra la misión, las entradas, el resultado, el responsable y lo que el agente puede y no puede hacer. Las herramientas, el modelo y las Skills son metadatos previstos para esta versión.

4

Simular y revisar

En Vista general, elige un proceso y simula una rutina, datos contradictorios o una solicitud fuera de la política. En Decisiones humanas, aprueba o devuelve con una justificación.

5

Evaluar la versión

Registra el resultado esperado, el resultado producido y la clasificación humana. Consulta la ficha del agente: la promoción didáctica exige 100 casos de la versión actual, alcanzar la meta, no tener errores críticos y resolver los pendientes.

6

Cerrar el ciclo de mejora

En Mejora continua, registra el problema, la hipótesis y la prueba. Para validar y promover un experimento, agrega evidencias. El cambio del agente crea una nueva versión y requiere una nueva evaluación.

7

Guardar y recuperar el trabajo

En Datos del laboratorio, exporta la copia JSON. Una importación reemplaza los registros actuales después de la confirmación. No hay cuenta ni sincronización entre dispositivos.

La herramienta en funcionamiento.

Captura real de la aplicación con los datos ficticios iniciales. Los indicadores se calculan a partir de los registros del laboratorio.

Cómo leer los indicadores

Una aprobación humana aumenta los casos completados, pero no el trabajo autónomo. Los casos pendientes y devueltos aparecen por separado.

El costo incluye todos los intentos. Las evaluaciones cuentan solo para la versión actual del agente.

El curso que acompaña el método

La propuesta tiene diez módulos y un proyecto aplicado. El plan ya está disponible; las clases están en desarrollo.
